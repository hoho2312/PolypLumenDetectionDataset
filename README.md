# Polyp_and_Lumen_Detection_Dataset
Extended-LDVideo dataset for simultaneous polyp and lumen bounding box detection in colonoscopy in the paper "A Simultaneous Polyp and Lumen Detection Framework Toward Autonomous Robotic Colonoscopy".  
You may download the dataset (in YOLO .txt format) [Here](https://drive.google.com/drive/folders/1IV5BSv0DI4fqCGRHknlUMWXeExSsfAjK?usp=drive_link)  
You may also download the colon phantom dataset (in VOC .xml format) [Here](https://gocuhk-my.sharepoint.com/:f:/g/personal/wingyinng_cuhk_edu_hk/IgCq8pX4P8vNRLoTEbzcNvSuAdKDLev5Zj73tRNrk_maZpQ?e=qJ0NdX)
